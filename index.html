설정

Gemini API 키

키는 이 기기(이 폰의 이 브라우저) 안에만 저장되고, 저장소나 백업 파일에는 들어가지 않아요. 키는 Google AI Studio(aistudio.google.com)의 'Get API key'에서 받을 수 있어요.

키를 저장하면 쓸 수 있는 모델을 불러와 Flash 계열을 자동으로 고릅니다. 바꾸면 바로 적용돼요.
